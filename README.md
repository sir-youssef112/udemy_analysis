
## Overview
This project analyzes Udemy courses data and presents key business insights through an interactive Excel dashboard.

The project focuses on cleaning and preprocessing raw data using Python, then transforming and visualizing the data inside Excel using Pivot Tables and charts.

---

## Tools & Technologies
- Python
- Pandas
- Excel
- Pivot Tables

---

## Project Workflow

### 1. Data Cleaning & Preprocessing
Using Python and Pandas:
- Removed duplicate records
- Handled missing values
- Fixed inconsistent data types
- Prepared the dataset for analysis and visualization

### 2. Data Analysis
Using Excel Pivot Tables:
- Revenue analysis by subject
- Subscriber analysis by course category
- Course level comparisons
- Lecture and duration analysis

### 3. Dashboard Creation
Built an interactive Excel dashboard including:
- KPI cards
- Pie charts
- Bar charts
- Slicers and filters

---

## Key Insights

- Technology and Business courses generated the highest overall revenue.
- Beginner-level courses attracted the largest number of subscribers.
- Short and medium-duration courses showed strong enrollment performance.
- Some subjects contain a much higher number of lectures, indicating deeper course content.
- Revenue and subscriber behavior vary significantly depending on course level and subject.
